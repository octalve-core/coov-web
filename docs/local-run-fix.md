# COOV local-run correction notes

This revision addresses the issues reported from the first Windows local run.

## What changed

- TypeScript is pinned to `6.0.3` because the current `typescript-eslint` dependency line used by Next.js supports TypeScript below `6.1.0`; TypeScript 7 caused ESLint to stop before linting.
- Navigation uses a discriminated `kind: "link" | "group"` model, removing the `href` / `children` union errors that blocked `pnpm typecheck` and `pnpm build`.
- Playwright navigation tests are scoped to the `Primary`, `Mobile primary`, and header/banner landmarks so duplicate footer links no longer cause strict-mode failures.
- Every `next/image` using `fill` now includes a responsive `sizes` hint.
- The root `<html>` includes `data-scroll-behavior="smooth"` because the site intentionally enables smooth scrolling.
- Vitest config is now `vitest.config.mts` to avoid the ESM-as-CommonJS configuration warning.
- `pnpm-workspace.yaml` approves the required `unrs-resolver` install script.
- Public company references now use `COOV Technologies Ltd`.

## Run this revision on Windows PowerShell

If you extract this revised ZIP into a fresh folder:

```powershell
corepack prepare pnpm@12.6.0 --activate
pnpm install
pnpm exec playwright install chromium
pnpm exec tsc --version
pnpm lint
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm build
pnpm dev
```

`pnpm exec tsc --version` should report `6.0.3`.

If you overwrite your existing folder instead of extracting fresh, use:

```powershell
pnpm install --force
pnpm rebuild unrs-resolver
```

before running the validation commands above.

## About the hydration warning

The reported attributes `data-new-gr-c-s-check-loaded` and `data-gr-ext-installed` are inserted by the Grammarly browser extension before React hydrates the page. They are not generated by the COOV source. Disable Grammarly for `localhost` (or test in an extension-free/incognito browser profile) if you want that development warning to disappear.
